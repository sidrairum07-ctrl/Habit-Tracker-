# ✦ Aesthetic Bullet Journal Habit Tracker & Daily To-Do Website ✦

A minimalist, warm-toned habit tracker website designed with bullet-journal aesthetics, inspired directly by your reference pictures:

- **Look & Grid Layout**: Styled like the yellow/cream grid tracker sheet (Image 2) with an inner off-white paper canvas, month headers, and sticky habit names.
- **Typography**: Clean, widely-spaced modern uppercase lettering (`Montserrat` display tracking) inspired by the Weekly Planner (Image 1).
- **Color Palette**: Muted earthy sage green (`#8A9A86`), deep forest slate (`#364837`), dusty rose (`#C69C94`), and warm linen/sand tones with subtle golden star accents (`✦`) inspired by Image 3.
- **Interactive Ticks & Wrongs**: Full support for checking off habits (✓ Tick) or marking them missed (✕ Cross) every day with tactile micro-animations and optional soft audio feedback.

## 🌟 Key Features

1. **Monthly Grid View (Image 2 Style)**:
   - Full 1 to 31 horizontal calendar sheet.
   - Click any box to toggle: **Empty → ✓ Tick (Sage Green) → ✕ Cross (Dusty Rose) → Empty**.
   - Sticky habit column so names remain visible as you scroll horizontally.
   - Real-time daily progress score and mini progress bar at the bottom.
   - Quick category filters: *All (20)*, *Spiritual (9)*, *DSA & Study (4)*, *Health & Habit (7)*.

2. **Today's To-Do Checklist View (Image 3 Style)**:
   - Categorized card layout for today's routine.
   - One-click `[✓]` Tick, `[✕]` Cross, and `[↺]` Reset buttons.
   - Day-stepper to check or back-fill previous days.
   - Live daily completion progress bar (e.g. `16 of 20 Completed • 80%`).
   - Daily Reflection / Basic Journal textarea (auto-saved).

3. **Insights & Streaks**:
   - Best streak tracker per habit (`🔥 Xd`).
   - Monthly consistency percentages.
   - Overview cards for highest consistency habit and total checks.

4. **Zero-Setup & Safe Storage**:
   - Everything is saved automatically to your browser (`localStorage`).
   - **💾 Backup**: Export your full progress to a `.json` file at any time.
   - **📥 Restore**: Easily import your backup file if you switch browsers or devices.
   - **🖨️ Print**: Clean print stylesheet formatted to print out as a physical paper habit sheet.
   - **🔔 Sound Toggle**: Subtle, peaceful audio synthesizer chime on clicks (toggleable).
